## 1. Pengenalan Website

Website Desa Sono adalah **media informasi resmi** yang dibuat untuk menyajikan berbagai informasi tentang Desa Sono kepada masyarakat secara digital. Website ini bertujuan untuk:

- ✅ Menyediakan informasi profil desa yang lengkap
- ✅ Menampilkan transparansi anggaran desa (APBDes)
- ✅ Mempublikasikan kegiatan dan dokumentasi desa
- ✅ Memudahkan akses informasi lokasi dan kontak desa
- ✅ Menampilkan galeri kegiatan, UMKM, dan tradisi desa

> **Catatan:** Website ini masih dalam tahap pengembangan dan akan terus ditingkatkan.

---

## 2. Cara Mengakses Website

### Dari Komputer/Laptop:
1. Buka browser favorit Anda (Chrome, Firefox, Edge, dll.)
2. Ketikkan alamat website di address bar
3. Tekan **Enter** untuk membuka website

### Dari Handphone:
1. Buka aplikasi browser di HP Anda
2. Ketikkan alamat website di address bar
3. Website akan menyesuaikan tampilan untuk layar HP secara otomatis

> **Tips:** Bookmark/simpan alamat website agar mudah diakses dikemudian hari.

---

## 3. Navigasi Website

Website memiliki **menu navigasi** di bagian atas yang terdiri dari:

| Menu | Fungsi |
|------|--------|
| **Beranda** | Halaman utama dengan ringkasan informasi desa |
| **Peta Desa** | Lokasi dan peta interaktif kantor desa |
| **Galeri Desa** | Dokumentasi foto kegiatan, UMKM, dan tradisi |

- **Di Komputer:** Klik menu yang diinginkan di bagian atas layar

## 4. Halaman Beranda

Halaman beranda adalah halaman utama yang menampilkan ringkasan seluruh informasi desa.

### Isi Halaman Beranda:

#### 4.1 Bagian Hero (Pembuka)
- Ucapan selamat datang di Website Desa Sono
- Tombol **"Profil Desa"** untuk scroll ke informasi desa
- Tombol **"Lihat APBDes"** untuk langsung mengakses dokumen anggaran

#### 4.2 Tentang Desa Sono
Berisi informasi lengkap tentang:
- Deskripsi dan sejarah singkat Desa Sono
- Wilayah desa (Sono, Buras, Jetis, Jurang, Glugu, Tegalrejo)
- **Statistik Desa:**
  - Luas Wilayah: 4,45 km²
  - Jumlah RT: 21 RT
  - Total Penduduk: 2.912 jiwa
  - Laki-laki: 1.439 jiwa
  - Perempuan: 1.473 jiwa

#### 4.3 Visi & Misi Desa
- **Visi:** "DENGAN SEMANGAT MEMBANGUN, MEWUJUDKAN DESA SONO MENCAPAI ADIL MAKMUR SEHAT DAN SEJAHTERA (AMURSETRA)"
- **Misi:** Terbagi menjadi kategori:
  - Desa Demokratis & Transparan
  - Desa Sejahtera & Religius

#### 4.4 Struktur Organisasi
Menampilkan foto dan jabatan perangkat desa:
- BPD (Badan Permusyawaratan Desa)
- Kepala Desa
- Sekretaris Desa
- Kepala Urusan (TU & Umum, Keuangan, Perencanaan)
- Kepala Seksi (Pemerintahan, Kesejahteraan, Pelayanan)
- Kebayan Dukuh (Buras, Glugu, Sono)

#### 4.5 Layanan Informasi
Menampilkan 4 layanan utama:
- Profil Desa
- Transparansi APBDes
- Peta Desa
- Galeri Desa

#### 4.6 Warta Desa
- Slider berita dan dokumentasi kegiatan desa
- Klik **"Detail"** untuk melihat narasi lengkap
- Klik **"Baca Berita Selengkapnya"** untuk halaman berita
- Gunakan tombol panah kiri/kanan untuk melihat berita lainnya

#### 4.7 Video Profil
- Video profil Desa Sono dari YouTube
- Klik tombol play untuk memutar video

#### 4.8 Transparansi & Akuntabilitas
- Ringkasan tentang komitmen transparansi desa
- Tombol **"Lihat Dokumen Transparansi"** menuju halaman transparansi

#### 4.9 FAQ (Pertanyaan Umum)
- Klik pertanyaan untuk melihat jawaban
- Berisi informasi seputar website dan layanan desa

## 11. Informasi Teknis Hosting Website

### Status Hosting Saat Ini

Website Desa Sono saat ini di-hosting menggunakan **Railway** dengan domain sederhana yang disediakan oleh platform tersebut.

| Informasi | Keterangan |
|-----------|------------|
| **Platform Hosting** | Railway (railway.app) |
| **Tipe Domain** | Domain bawaan Railway |
| **Status** | Aktif dan dapat diakses publik |

### Tentang Railway

Railway adalah platform cloud hosting modern yang menyediakan:
- ✅ Deployment otomatis
- ✅ SSL/HTTPS gratis
- ✅ Uptime monitoring
- ✅ Mudah dikelola

### Migrasi ke Hosting Kominfo

Jika di kemudian hari website ini akan di-hosting oleh **Dinas Kominfo** atau pihak pemerintah lainnya, berikut informasi teknis yang diperlukan:

#### Spesifikasi Teknis Website:
| Komponen | Keterangan |
|----------|------------|
| **Framework** | Laravel (PHP) |
| **Bahasa Pemrograman** | PHP 8.x |
| **Database** | MySQL / MariaDB |
| **Web Server** | Apache / Nginx |
| **Storage** | Minimal 500MB |

#### Langkah Migrasi:
1. **Backup Data** - Unduh seluruh source code dan database dari Railway
2. **Setup Server** - Siapkan server dengan PHP 8.x dan MySQL
3. **Upload Files** - Transfer semua file ke server baru
4. **Konfigurasi** - Sesuaikan file `.env` dengan kredensial server baru
5. **Import Database** - Restore database ke server baru
6. **Pointing Domain** - Arahkan domain resmi (jika ada) ke server baru

#### Kontak untuk Migrasi:
Untuk informasi teknis lebih lanjut terkait migrasi hosting, dapat menghubungi:
- **Tim Developer:** Tim KKN-R UNDIP 120
- **Dokumentasi Teknis:** Tersedia dalam repository source code

> **Catatan:** Proses migrasi memerlukan koordinasi antara pihak Desa, Kominfo, dan Tim Developer untuk memastikan kelancaran transisi.
